    04 · The evidence

    A Tree With Only Three Questions

    The unscaled decision tree grows to depth 3 with just 4 leaves. It asks three questions, and nothing else, yet classifies all 11,200 test days perfectly. The thresholds below are the exact split values it learned.

    Humidity > 65.01 %?
    No → NO RAINYes ↓
    Cloud > 4.5 oktas? (i.e. 5–8)
    No → NO RAINYes ↓
    Rainfall today > 2.01 mm?
    No → NO RAINYes ↓
    🌧 RAIN TOMORROW

    Trees ignore scaling, so the notebook re-trains this display tree on the original unscaled values — the questions above are asked in real units (% · oktas · mm) and it still scores 1.0 on the test set. Rounded, the same rule is Humidity > 65 AND Cloud > 4.5 AND Rainfall > 2, and it matches 100.00% of all 55,996 rows (notebook “Verify” cell).

    05 · Field notes

    Dataset & Honest Findings

    The dataset

    • 55,996 rows × 9 columns — 8 numeric features + target RainTomorrow (binary classification).
    • Features: MinTemp, MaxTemp, Rainfall, Humidity, Pressure, WindSpeed, WindGustSpeed, Cloud (0–8 oktas).
    • Target split: 45,579 dry (81.4%) vs 10,417 rainy (18.6%).
    • Preprocessing: StandardScaler on all features, fitted on train only. No encoding needed — everything is numeric.
    • Source: Kaggle — jayavantwarkhade.

    Clean — almost too clean

    • 0 missing values, 0 duplicates, 0 outliers (IQR rule). No imputation was needed — the opposite of the churn dataset.
    • Kept and reported, not deleted: MinTemp > MaxTemp in 6,918 rows (12.4%); WindGustSpeed < WindSpeed in 21,129 rows (37.7%).
    • Those impossible patterns are evidence the data is synthetically generated — deleting up to 38% of rows would help nothing.
